# QNB Group — Machine Learning Business Cases

Executive presentation for the QNB Group Executive Committee and Board of Directors, plus a Phase 0 **BRS Discovery Pack** for dual deployment paths.

## Open the deck

Open `index.html` in a modern browser, or serve locally:

```bash
cd qnb-ml-presentation
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Navigation

- **Arrow keys** / **Space** / **Page Up·Down** — move between slides
- **On-screen controls** — previous / next
- **Swipe** — on touch devices
- **Print** — browser print yields one slide per page
